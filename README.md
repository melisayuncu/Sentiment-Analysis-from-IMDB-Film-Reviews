# Sentiment-Analysis-from-IMDB-Film-Reviews
Sentiment analysis on IMDB movie reviews using LSTM, GRU, BiLSTM, and BERT, compared against Logistic Regression and SVM. Includes GloVe embeddings, hyperparameter tuning, and evaluation.

Sentiment analysis is a natural language processing (NLP) task that aims to automatically determine whether a piece of text expresses a positive, negative, or neutral sentiment.
In this study, sentiment analysis was performed using the IMDb movie reviews dataset [1]. The project was designed in two main stages: first, a comparative analysis of different deep learning architectures (Simple RNN, LSTM, BiLSTM, and GRU); second, a comparison of these deep learning models with traditional machine learning methods (TF-IDF + Logistic Regression and TF-IDF + SVM). In addition, a BERT-based learning approach was also evaluated under limited data conditions.

The main objective of this study is to answer the following question: Do deep learning models always outperform traditional machine learning methods in text classification tasks? The obtained results provide an interesting perspective on this question.

[1] https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews
